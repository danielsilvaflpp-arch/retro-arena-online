# Retro Arena Host V1 (experimental)
Envie os arquivos deste ZIP mantendo a pasta public, sem remover os arquivos existentes. Configure HOST_PASSWORD no Render (senha exclusiva de pelo menos 16 caracteres). Faça deploy do último commit. No PC abra /host.html no Chrome, ative a máquina e mantenha a aba visível. No celular selecione Solo/Duo, jogo e máquina; informe o código exibido pelo Host. Duo: copie o convite para P2. Uma partida por máquina; sair ou desconectar encerra a sessão. Áudio opcional: no Host, selecione compartilhar esta aba com áudio. A descoberta usa Render, não mDNS; a lista não comprova que os dispositivos estão na mesma LAN. WebRTC tenta conexão direta, inclusive local; TURN pode ser necessário. Não há execução de comandos do sistema. Não coloque senhas no GitHub. Não inclui ROMs. Testes de sintaxe somente; não testado em dispositivos reais. Caso o emulador não inicie automaticamente, clique nele no PC. Preserve a versão anterior para rollback.
